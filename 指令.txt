# 项目常用指令

本文档只保留当前仍有用的启动、检查、构建和调试命令。旧开发流程记录已移除。

## 1. 首次准备

### 后端依赖

```powershell
Set-Location D:\LiMinglong\workspace_ai_assistant
& .\.venv\Scripts\Activate.ps1
$env:PIP_DISABLE_PIP_VERSION_CHECK='1'
python -m pip install -r requirements.txt
```

### 前端依赖

```powershell
Set-Location D:\LiMinglong\workspace_ai_assistant\client
npm install
```

## 2. 日常启动

### 终端 1：启动后端

```powershell
Set-Location D:\LiMinglong\workspace_ai_assistant
& .\.venv\Scripts\Activate.ps1
Remove-Item Env:HTTP_PROXY -ErrorAction SilentlyContinue
Remove-Item Env:HTTPS_PROXY -ErrorAction SilentlyContinue
$env:NO_PROXY='127.0.0.1,localhost,::1'
python server.py
```

### 终端 2：启动桌面前端

```powershell
Set-Location D:\LiMinglong\workspace_ai_assistant\client
Remove-Item Env:HTTP_PROXY -ErrorAction SilentlyContinue
Remove-Item Env:HTTPS_PROXY -ErrorAction SilentlyContinue
$env:NO_PROXY='127.0.0.1,localhost,::1'
$env:BACKEND_URL='http://127.0.0.1:8000'
npm run dev
```

## 3. 常用检查

### 后端健康检查

```powershell
Invoke-RestMethod -Uri "http://127.0.0.1:8000/health" -Method Get
```

### 普通聊天接口

```powershell
$body = @{
  user_id = "user1"
  session_id = "test-chat"
  messages = @(@{ role = "user"; content = "用一句话介绍你现在能做什么" })
} | ConvertTo-Json -Depth 6

Invoke-RestMethod -Uri "http://127.0.0.1:8000/chat" -Method Post -ContentType "application/json" -Body $body
```

### 项目资料 RAG 对话

```powershell
$body = @{
  user_id = "user1"
  session_id = "course_1_test"
  use_retrieval = $true
  document_ids = @(1)
  messages = @(@{ role = "user"; content = "请总结这份资料的核心知识点" })
} | ConvertTo-Json -Depth 6

Invoke-RestMethod -Uri "http://127.0.0.1:8000/chat" -Method Post -ContentType "application/json" -Body $body
```

## 4. 模型与配置

- 模型 API 推荐在前端“设置 -> 模型 API”里填写，后端会写入 `data/runtime/provider_config.json`。
- 也可以用环境变量覆盖：

```powershell
$env:REMOTE_PRIMARY_API_BASE_URL='https://api.deepseek.com'
$env:REMOTE_PRIMARY_API_KEY='你的key'
$env:REMOTE_FAST_MODEL='deepseek-v4-flash'
$env:REMOTE_HEAVY_MODEL='deepseek-v4-pro'
```

- 数据库默认连接：

```powershell
$env:DATABASE_URL='postgresql://checker:114514@localhost:5432/postgres'
```

## 5. 语音能力

默认 STT 配置走本地 sherpa-sense-voice：

```powershell
$env:STT_PROVIDER='sherpa_sense_voice'
$env:LOCAL_STT_SHERPA_MODEL_DIR='D:\models\sherpa-sense-voice'
$env:LOCAL_STT_SHERPA_MODEL_FILE='model.int8.onnx'
$env:LOCAL_STT_SHERPA_TOKENS_FILE='tokens.txt'
$env:LOCAL_STT_SHERPA_PROVIDER='cpu'
$env:LOCAL_STT_SHERPA_NUM_THREADS='2'
$env:LOCAL_STT_SHERPA_SAMPLE_RATE='16000'
$env:LOCAL_STT_SHERPA_LANGUAGE='auto'
```

首次准备本地 STT 模型：

```powershell
$modelUrl='https://github.com/k2-fsa/sherpa-onnx/releases/download/asr-models/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2025-09-09.tar.bz2'
$tmp='D:\models\_tmp_sherpa_sense_voice'
$target='D:\models\sherpa-sense-voice'
New-Item -ItemType Directory -Force -Path $tmp | Out-Null
Invoke-WebRequest -Uri $modelUrl -OutFile "$tmp\model.tar.bz2"
tar -xjf "$tmp\model.tar.bz2" -C $tmp
$src = Get-ChildItem -Path $tmp -Recurse -Directory |
  Where-Object { (Test-Path "$($_.FullName)\model.int8.onnx") -and (Test-Path "$($_.FullName)\tokens.txt") } |
  Select-Object -First 1
if (-not $src) { throw '未找到 model.int8.onnx/tokens.txt，请检查下载是否完整' }
New-Item -ItemType Directory -Force -Path $target | Out-Null
Copy-Item "$($src.FullName)\model.int8.onnx" "$target\model.int8.onnx" -Force
Copy-Item "$($src.FullName)\tokens.txt" "$target\tokens.txt" -Force
```

## 6. 桌面端项目 CLI

进入某个项目对话后，右上角 `CLI` 按钮会在该项目根目录打开 PowerShell。项目根目录来自后端返回的 `project_path`，通常位于：

```text
D:\LiMinglong\workspace_ai_assistant\data\projects
```
